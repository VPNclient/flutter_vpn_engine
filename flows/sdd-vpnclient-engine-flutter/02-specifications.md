## Overview

The VPN Client Engine is a Flutter plugin providing a unified interface for VPN functionality across Android, iOS, Windows, Linux, and macOS. It follows a layered architecture separating protocol handling (Cores) from traffic tunneling (Drivers), with FFI-based communication between Dart and C++ layers.

## Affected Systems

| System | Impact | Notes |
|--------|--------|-------|
| Flutter Application | Consumer | Uses VpnClientEngine singleton |
| Dart FFI Layer | Core | VpnEnginePlatform bindings |
| C++ Native Engine | Core | VPNClientEngineImpl |
| Core Implementations | Core | SingBoxCore, LibXrayCore, V2RayCore |
| Driver Implementations | Core | HevSocks5Driver, Tun2SocksDriver |
| Android VPNService | Platform | Native VPN establishment |
| iOS NetworkExtension | Platform | PacketTunnelProvider |

## Behavior Specifications

### Connection Lifecycle

1. Call `initialize(config)` with core and driver configuration
2. Native engine created via FFI
3. Call `connect()` to establish VPN
4. Driver starts (if required for core type)
5. Core starts
6. Status changes: disconnected -> connecting -> connected
7. Stats polling begins (1 second interval)
8. Call `disconnect()` to terminate
9. Core stops, then driver stops
10. Status changes: connected -> disconnecting -> disconnected
11. Call `dispose()` to release all resources

### Core/Driver Matrix

| Core | Requires Driver | Recommended Driver |
|------|-----------------|-------------------|
| SingBox | No | None |
| LibXray | Yes | HevSocks5 |
| V2Ray | Yes | HevSocks5 |
| WireGuard | No | None |

### Error Handling

| Error | Cause | Response |
|-------|-------|----------|
| Core init failure | Invalid config JSON | Status -> error, log message |
| Driver init failure | TUN permission denied | Status -> error, log message |
| Connection timeout | Server unreachable | Status -> error, auto-disconnect |
| FFI failure | Library not loaded | Exception thrown |
